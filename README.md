# Design Library

Static website prepared for https://monagyai.github.io/designlibrary/.
460 menu entries point to their exact source HTML filenames (458 distinct pages).
Other supplied design pages are retained for existing links. Courses, software,
and marketing-data pages and folders are excluded.

Upload these files to the repository root, keeping their filenames unchanged.
Enable Settings > Pages > Deploy from a branch > main > /(root).
The .nojekyll file ensures filenames beginning with underscores are served.

The Android Kodular project opens this website directly. app_navigation.js
routes external preview and download links to Android's external browser;
internal category pages stay inside the application. The same website works in
ordinary desktop and mobile browsers.

Resource files and thumbnails remain hosted at their original Google Drive /
external locations. The site package contains the HTML listings, not the actual
PSD archives, fonts, or design resource downloads.

This package has not been deployed automatically.
