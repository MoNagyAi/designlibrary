# نسخ قسم رئيسي من Pages CMS

تمت إضافة زر **نسخ قسم رئيسي** داخل صفحة **الأقسام الأساسية — الرئيسية**.

عند الضغط عليه أدخل:
- `ID القسم الأصلي` مثل `courses`.
- `ID القسم الجديد` مثل `photography` — يجب أن يكون فريدًا.
- الاسم العربي/الإنجليزي الجديد (اختياري).
- **نسخ محتويات القسم**: ينسخ عناصر `library-content.json` ويعطيها IDs جديدة تلقائيًا.
- **فتح النسخة مباشرة**: إذا لم تفعلها، تُنشأ النسخة بحالة `قريبًا` للأمان.

ملاحظات:
- Pages CMS لا يوفر Duplicate أصليًا داخل كل عنصر من قائمة object؛ الزر هنا هو Pages CMS Action مدعوم رسميًا ويشغّل GitHub Action.
- لو كان `target = cms`، يتم تعديل الرابط تلقائيًا إلى `section.html?section=<new_id>`.
- ترتيب الأقسام يبقى حسب ترتيب القائمة، ويتم تحديث أرقام `order` القديمة تلقائيًا بعد النسخ.
- الإحصائيات تبقى منفصلة لأن النسخة الجديدة لها ID جديد.
